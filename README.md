# 🌱 Developer Flowerbed

My public study notebook. I'm growing it from the basics up to full-stack web development, one small plant at a time.

Part of the goal is to prove what I can build. The other part is to leave notes for future me, who will forget everything.

## What's growing here

| Patch | What |
|---|---|
| `00-foundations` | Git, CLI, dev setup, how the web works |
| `01-java-basics` | Core Java, OOP, collections, streams, concurrency |
| `02-algorithms` | Data structures and algorithms in Java, with tests |
| `03-web-core` | HTTP, HTML, CSS, TypeScript groundwork |
| `04-backend-java` | Spring Boot, REST, SQL, auth |
| `05-frontend-angular` | Angular + TypeScript |
| `06-fullstack` | Angular + Spring Boot projects |
| `agentic-coding` | Using AI agents in a real Java workflow (what worked, what didn't) |
| `cheatsheets` | One-pagers I'll actually reread |

## The stack

- **Java** for the basics, algorithms and backend
- **Angular + TypeScript** for the frontend
- **AI agents** as a tool in the workflow, never a replacement for understanding

## How I work

- Small topics, often. Each one has a short README, code, and tests.
- Notes are written in my own words, including the parts that confused me.
- Nothing here is a polished textbook. It's a notebook that's getting better.

*Started November 2026. Still sprouting.*
